## Mozilla CA certificate list

`romfs/cacert.pem` is the list of CA certificates from Mozilla, as extracted by the curl project
(https://curl.se/docs/caextract.html). It is subject to the Mozilla Public License, version 2.0
(https://mozilla.org/MPL/2.0/). The file is distributed unmodified; its source is linked in its header.

## C and C++ runtime

The app is built with devkitARM. Its C library is newlib, whose parts are under BSD-style and similar
permissive licenses (https://sourceware.org/newlib/COPYING.NEWLIB). Its C++ library, libstdc++, is under
the GPL version 3 with the GCC Runtime Library Exception (https://www.gnu.org/licenses/gcc-exception-3.1.html).
